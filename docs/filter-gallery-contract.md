# Filter Gallery contract

`Filter > Filter Gallery…` is a local gallery for PixelForge's existing
quick-filter presets (Original, Vivid, Mono, Warm and Cool). It uses the same
command definitions as the toolbar and command search, provides a searchable
card layout, and applies one editable local preset to the selected layer. It
does not upload pixels, flatten the layer, or claim Photoshop's full gallery
algorithm set. The selected layer remains source-safe and the existing filter
control stays available for further editing.

The dialog is keyboard-focusable, closes with Escape or Close, and is covered by
desktop and mobile browser tests for search, selection and resulting state.
