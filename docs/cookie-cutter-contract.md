# Cookie Cutter contract

Edit → Cookie Cutter Mask… creates a nondestructive editable vector mask on a
visible unlocked pixel-producing layer. The local preset set is bounded to
rectangle, ellipse, triangle, star, and hexagon. The mask is stored as a
validated closed path, so Direct Selection can refine it after creation and
undo/reload/project export retain the source raster unchanged.

This is a local shape-mask tool. It does not infer objects, trace silhouettes,
or claim Photoshop's arbitrary custom-shape library. Existing vector masks must
be removed before a new Cookie Cutter mask is created.
