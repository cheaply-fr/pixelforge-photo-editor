If something does not work as described in this Help Center, first check [Troubleshooting](troubleshooting) and the [FAQ](faq). If that does not solve it, please tell us.

## How to contact us

PixelForge is made by Cheaply. Use the contact options on the Cheaply website at [www.cheaply.fr](https://www.cheaply.fr) to send a bug report or a suggestion. You can also reach this page from **Help > Report a Problem** in the editor.

## What to include

The more of this you include, the faster we can find the problem:

1. **The PixelForge version.** It is shown in the top bar next to the server status, for example `v0.1.1054`. Hovering over it also shows the exact build.
2. **Your browser and device.** For example "Chrome 131 on Windows 11" or "Safari on iPhone 15, iOS 18".
3. **What you did, step by step.** Which menu commands, tools and options you used, in order.
4. **What you expected and what happened instead.**
5. **Any message** shown in the status line at the bottom of the editor or in a dialog. Copy the exact words.
6. **The document size and layer count**, if the problem is about speed or limits. The size is shown next to the document name, the layer count at the top of the Layers panel.
7. **The file type**, if a file would not open or export (for example "16-bit TIFF" or "iPhone HEIC photo").

![The version and server status in the top bar](img/release-status.jpg "The version is shown next to the server status")

> [!IMPORTANT]
> Do not send private photos, passwords or account details. If an image is needed to show the problem, try to reproduce it with a picture you are happy to share, such as a plain test image.

## Before you report

- Reload the page. If a **New version available** notice appears, choose **Reload**; the problem may already be fixed. See [What's new](whats-new).
- Try again in a new draft (**File > New white document**) to see whether the problem depends on one document.
- If you can, try another browser. See [Browser support](browser-support).
