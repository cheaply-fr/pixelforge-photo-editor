PixelForge has separate commands for turning the whole document and for turning a single layer. Each command is one undo step and keeps your layers editable.

![The Image menu with Rotate left, Rotate right, Rotate 180°, Flip horizontal and Flip vertical highlighted](img/image-menu-rotate.jpg "Document rotation commands in the Image menu")

## Rotate or flip the whole document

Use the **Image** menu:

| Command | Result |
|---|---|
| **Image > Rotate left** | Turns the document 90° counterclockwise. Width and height swap. |
| **Image > Rotate right** | Turns the document 90° clockwise. Width and height swap. |
| **Image > Rotate 180°** | Turns the document upside down. |
| **Image > Flip horizontal** | Mirrors the document left to right. |
| **Image > Flip vertical** | Mirrors the document top to bottom. |

The same four buttons (Rotate left, Rotate right, Flip horizontal, Flip vertical) are in the **Transform** panel under **More panels** in the properties sidebar.

All layers, masks and the canvas turn together.

## Rotate or flip one layer

Use the **Edit** menu. These change only the active layer:

- **Edit > Transform → Rotate 90° Clockwise**
- **Edit > Transform → Rotate 90° Counterclockwise**
- **Edit > Transform → Rotate 180°**
- **Edit > Transform → Flip Horizontal**
- **Edit > Transform → Flip Vertical**

For any other angle, use [Free Transform](free-transform). To level a tilted horizon, use **Straighten** in the [Crop tool](crop-and-straighten) or **Straighten Layer** with the [Ruler](measure-count-and-notes).

> [!NOTE]
> **View > Rotate View left 15°**, **Rotate View right 15°** and the Rotate View tool only turn your view of the canvas to make drawing easier; they never change the image. See [Zoom, pan and rotate the view](zoom-pan-and-rotate-view).
