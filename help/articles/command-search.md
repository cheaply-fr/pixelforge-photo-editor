Command search finds any command in the menus by name. It is the fastest way to reach a command when you don't remember which menu it lives in.

![The Search commands dialog with "gauss" typed, showing Gaussian Blur… from the Filter menu](img/command-search.jpg "Search commands")

## Search and run a command

1. Press <kbd>Ctrl</kbd>+<kbd>F</kbd> (<kbd>⌘</kbd>+<kbd>F</kbd> on Mac), or choose **Edit > Search**.
2. Type part of the command's name, or the name of its menu, for example *gauss*, *rotate* or *mask*.
3. Click a result to run it. The dialog closes and the command runs exactly as if you had chosen it from the menu.

Each result shows the menu it comes from and its shortcut, if it has one. Up to 30 results are listed, so type a few more letters if you don't see what you need.

## Unavailable commands

Results that cannot run right now are shown dimmed and cannot be clicked, for example **Merge Layers** with only one layer selected. Commands that are listed in the menus but not available yet are also shown dimmed. The rules are the same as in the menus.

## Close

Click **Close** or press <kbd>Esc</kbd>.

> [!NOTE]
> Search looks only at command names; your search text is not sent anywhere. To find words inside your type layers, use **Edit > Find and Replace Text…** (see [Find, replace and check spelling](find-replace-and-spellcheck)). To find layers by name, use the **Find layers** box in the [Layers panel](layers-panel).
