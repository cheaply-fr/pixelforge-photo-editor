PixelForge keeps a copy of the editor in your browser after you have used it online, so you can keep editing on a train, a plane or a bad connection.

## How it works

1. Open [the editor](/editor) once while you are online. The browser stores the editor's files.
2. Later, without a connection, open the same address (or your bookmarked draft). The editor and your drafts open from the browser.
3. The top bar shows **Offline · local editing**. Edit, autosave, download project files and export images as usual.

Editor features and fonts are stored as you use them. Something you have never opened before, such as a font you have not used yet, may need a connection the first time.

## What needs a connection

- Signing in and everything in [Cloud projects](cloud-projects).
- Updates: a **New version available** notice appears when you are back online and a new version exists.
- This Help Center may not be available offline.

## Install as an app

PixelForge can be installed like an app, with its own window and icon:

- **Chrome or Edge on a computer:** use the install icon in the address bar, or the browser menu's install option.
- **Android:** browser menu > **Install app** or **Add to Home screen**.
- **iPhone and iPad (Safari):** Share > **Add to Home Screen**.

On a computer and on Android, the installed app shares its storage with the website in the same browser, so you see the same drafts. On iPhone and iPad, a Home Screen app keeps its own separate storage: drafts made in Safari do not appear in it, and the other way round. Use a project file to move work between them.

> [!WARNING]
> Offline or installed, your drafts still live only in the browser's storage on this device. Download project files to keep copies you control. See [Drafts and saving](drafts-and-saving).
